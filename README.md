# 每日开源项目推荐

**同一个仓库，每天新增一份按日期命名的资料，每份推荐 5 个项目，跨全部历史去重。** 每个项目配一张用途图和一个具体例子，用简短中文说明能做什么、何时值得用。

只使用公开资料和通用应用建议；旧文档保留，首页持续列出新旧资料。

**最新资料：[2026-10-29](reports/2026-10-29.md)** · 每天 09:00（北京时间）

## 先看这份资料

想把学习资料变成讲解和练习，先看 **DeepTutor**；想在一个界面提需求、写代码和审查改动，先看 **ThinkRail**；想把一次电脑操作整理成可复用步骤，先看 **Skill Recorder**。另外两项分别帮助检查工作说明中的风险、限制程序的文件和联网权限。

**阅读方式**　速览选项目 → 点名称 → 看三步图解 → 看具体例子和使用门槛。
