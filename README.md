# 每日开源项目推荐

## 数据怎么选

每天读取总周榜和 Python、TypeScript、JavaScript、Go、Rust、Swift、Dart、Java 周榜，核对历史推荐、许可证与用途，选取 5 个未介绍过的项目。热度指标是滚动一周，不是单日新增量；这是这些榜的样本池。项目改名时，结合 GitHub 仓库标识去重。
