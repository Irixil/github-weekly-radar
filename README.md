# 每日开源项目推荐

## 先看这份资料

想让编程助手按步骤澄清需求、实现和检查，先看 **Superpowers**；想把文字改得直接自然，先看 **Humanizer**；想整理产品页面和营销方案，先看 **marketingskills**。**OpenMausBot** 与 **OpenBot** 则分别提供聊天式多助手界面、可部署在自有环境的助手平台，采用前先看权限和服务费用。
